# Documents Folder

Place your PDF files here. Each PDF should match the filename referenced in `src/data/documents.ts`.

## Naming Convention
Use kebab-case filenames, e.g.:
- `designation-master-guide.pdf`
- `user-onboarding-manual.pdf`

## Adding a New Document
1. Drop the PDF file into this folder
2. Add an entry in `src/data/documents.ts` with the matching `pdfFile` path
